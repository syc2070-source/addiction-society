## 3. validate_palette — 바탕 blue-0 · card 둘 다 (dark 모드 · 유형 순서 = 인접 쌍)

| 검사 | 지시서 후보 그대로(blue-0) | 쓴 값(blue-0) | 쓴 값(card) |
|---|---|---|---|
| 밝기 띠 L 0.48~0.67 | FAIL | FAIL | FAIL |
| 채도 바닥 0.10 | FAIL(알코올 0.053) | PASS | PASS |
| 색각 이상 인접 쌍 ΔE ≥ 8 | PASS(10.0) | PASS(11.0 마약↔도박) | PASS(11.0) |
| 정상 시각 인접 쌍 ΔE ≥ 15 | FAIL(13.5 게임↔스마트폰) | PASS(15.7) | PASS(15.7) |
| 바탕 대비 ≥ 3:1 | PASS | PASS | PASS |

**밝기 띠 FAIL 은 고칠 수 없음(구조)**: validate_palette 의 어두운 띠(L ≤ 0.67)는 검정에 가까운 바탕(#1a1a19)을 기준으로 잡은 것.
--blue-0(#2b4763)은 그보다 훨씬 밝아, 색상을 지킨 채 L ≤ 0.67 로 내리면 마약·게임은 3:1 을 넘는 값이 없다(tune_blue.mjs 전수 탐색: L 0.48~0.67 × C 전 범위 — 「NONE」),
알코올·도박·스마트폰·담배도 3.0~3.4:1 의 탁한 색이 된다. → 대비(읽힘)를 지키고 띠는 FAIL 로 둔다. 다섯 검사 가운데 넷 PASS.
R20 의 「서로 밝기로도 구별됨」(쌍 휘도 비)은 여전히 가까움(가장 가까운 쌍 알코올↔도박 1.02) — 색만으로 가르지 않는다: 유형 이름이 언제나 색 옆에 글로 붙고, 여섯이 한 그림에 겹치지 않는다.
