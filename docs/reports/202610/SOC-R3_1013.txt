정직 표기
 - ■4 를 일 단위가 아니라 월 단위로 구현함(지시서 문장 「next_expected_at < 오늘」과 다름). 이유: 예정은 월 정밀도(1일로 저장)이고 기존 시험이 「이번 달 예정은 1일이 지났어도 지난 것이 아니다」를 못 박아 둠. 일 단위면 매달 2일부터 「이번 달 발표 예정」이 늘 비고, 10월 국정감사 자료(mohw)가 10-13 에 2027-10 으로 밀려 「발표가 내년」이라는 틀린 말을 하게 됨. 일 단위가 맞다면 next-expected.util 의 비교 기준 한 줄(monthStartOf → 오늘)로 바꿀 수 있음 — CTO 판정 요청
 - 홈 「이번 달 발표 예정」 화면 동작은 바뀌지 않음(원래도 이번 달 것만 · YYYY-MM 표시). 바뀐 것은 달력의 지난 예정 줄과 로그·끝점
 - kcgp 2015·2018 은 2022 와 모집단(중1~고2 vs 초4~고3)·회상 기간이 다름 — 각 관측치 note 에 「회차 간 직접 비교 주의」. 홈 작은 추세선은 note 를 보이지 않음(지표 자세히에서 보임). 다만 홈에는 흡연(10점)이 뜰 것으로 보여 kcgp 선이 첫 화면에 오를 가능성은 낮음
 - kcgp 2015 의 「5.1」은 2015 보고서가 아니라 2019 보도자료에 적힌 값(보고서는 4.0·1.1 따로) — 4.0+1.1 과 맞지만 출처는 보도자료로 적음
 - 2015 보고서 쪽 번호는 내려받은 PDF 의 글자 뽑기(pdftotext)에서 쪽 나눔으로 셈 — 화면으로 넘겨 확인하지 않음
 - 고위험음주율 값은 KOSIS 저장본에서 대조(이 판 안에서 KOSIS 가 연속 요청으로 IP 를 막아 다시 받지 못함). 흡연은 직접 다시 받아 같음
 - 고위험음주율·흡연율 모두 표준화율을 씀(조율과 다름 — 2024 조율 고위험음주율 12.7 / 표준화 13.6)
 - kdca_knhanes 예정 월 1월은 e-나라지표 갱신 예정(2027-01-29) 표기에서 옴 — 국민건강통계 원 공표 월은 확인하지 않음
 - 「오늘의 숫자」가 흡연율로 뜰 것은 규칙(점 수 → code 순)으로 본 예상일 뿐 미측
 - nightly 의 숫자는 각 단계가 스스로 찍은 [job_counts] 줄 — 찍기 전에 죽은 단계는 counts null
 - 달력 화면 「지난 예정 · 미확인」 렌더: 16:05~16:11 은 옛 캐시(0) → 16:11:44 www /calendar 에 「2026-08 예정 지남 · 다음 2026-09」 「2026-09 예정 지남 · 다음 2026-10」 (마약류 통계) 두 줄 확인
